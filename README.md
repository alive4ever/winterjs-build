# WinterJS Build for some architectures

## Motivation

WinterJS is yet another js runtime, based on Mozilla Spidermonkey engine. There is no ready built binary releases on the project page, so here is my attempt to build native WinterJS for some platforms.

## How to use

Grab the built binaries on the releases page.
